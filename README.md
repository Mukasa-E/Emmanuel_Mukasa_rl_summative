# Emmanuel Mukasa RL Summative

Mission-based Reinforcement Learning summative assignment. A custom,
non-generic precision-agriculture environment is used to compare four
reinforcement-learning algorithms implemented with **TorchRL**:

* **DQN** (value-based)
* **REINFORCE** (policy gradient)
* **PPO** (proximal policy optimization)
* **A2C** (actor-critic)

## Mission context

The environment is derived from the AgriMind AI capstone mission
(agricultural decision-support for smallholder farmers). Here the RL agent is
an autonomous field agent (robot/drone) that navigates a farm plot, monitors
crop health, and applies the right treatment (water, fertiliser, pesticide) or
harvests at the right time — while managing battery and time.

## Getting started (uv only)

The marker should be able to clone and run the project using **only** `uv`:

```bash
# 1. Clone the repository
git clone <your-repo-url>
cd student_name_rl_summative

# 2. Sync dependencies and lockfile (creates the .venv)
uv sync

# 3. Run hyperparameter sweeps + training for all four algorithms
uv run main.py

# 4. Run the best-performing agent with the GUI (play.py)
uv run play.py
```

No manual virtual-environment creation or dependency installation is required.
